# Хаб

Одно окно для всех твоих проектов: план на день, бэклог по проектам и аналитика по неделям, месяцам и году. Хаб живёт в артефакте Claude с базой. Твои проекты в Claude сами записывают туда задачи и отмечают сделанное.

**Посмотреть, как это выглядит:** [демо с выдуманными проектами](https://claude.ai/artifact/1bztRYM6tQbyzj7hDZx2wP). Нажимать можно всё, после перезагрузки демо возвращается к исходному.

## Что внутри

- **План на сегодня.** Собираешь день из бэклога, порядок меняешь перетаскиванием. Незакрытое со вчера хаб предложит оставить или вернуть в бэклог.
- **Бэклог по проектам.** Задачи от 30 минут до 3 часов, разбитые по разделам. Есть фильтры по размеру, «в работе», «ждёт» и тегам.
- **Аналитика.** Сколько закрыто и куда ушло время, план против факта, сроки при текущем темпе и что застряло.
- **Проекты Claude пишут сами.** Подключённый проект раскладывает план на задачи, отмечает сделанное и в начале сессии узнаёт, что ты поменял в хабе без него.

Светлая и тёмная темы, телефон.

## Как поставить

Нужен тариф claude.ai, на котором Claude публикует артефакты с базой. Если не выходит — напиши в [Issues](https://github.com/Qrootto/claude-hub/issues).

1. Открой новый чат в [claude.ai](https://claude.ai) и отправь этот промт:

   ```
   Поставь мне «Хаб» — личный хаб для всех проектов.
   1. Скачай файлы index.html, hub.css, hub.js, analytics.css и analytics.js из репозитория https://github.com/Qrootto/claude-hub (ветка main). Не меняй в них ни символа.
   2. Опубликуй их одним артефактом с названием «Хаб». Публикуй файлами, не переписывай код.
   3. Объяви у артефакта capabilities db и user.
   4. Запиши в базу артефакта документ meta/hub: {"url": "<адрес опубликованного артефакта>"}.
   5. Пришли мне ссылку.
   Если скачать с GitHub не получается, скажи — я прикреплю файлы сам.
   ```

2. Открой ссылку. Хаб пустой и предложит завести первый проект.
3. Заведи проект прямо в хабе («Новый проект») или подключи проект Claude: в том же окне на вкладке «Подключить проект Claude» есть блок для инструкции проекта и кнопка «Скопировать блок».

**Если Claude не может скачать файлы.** Нажми на этой странице Code → Download ZIP и распакуй архив. Прикрепи в чат пять файлов (index.html, hub.css, hub.js, analytics.css, analytics.js) и отправь тот же промт, только вместо первого пункта напиши «Возьми прикреплённые файлы».

## Как устроено

Пять файлов без сборки: ванильный JS, CSS и шрифт Inter с Google Fonts. Данные хранятся в базе артефакта:

| Коллекция | Что там |
|---|---|
| `projects` | проекты: название, тип (обязательный / ключевой / хочу), цель, срок, разделы, «где мы сейчас» |
| `tasks` | задачи: проект, раздел, часы, закрыта ли и когда, в плане ли на день, в работе, кого ждём |
| `days` | что было в плане по дням, для сравнения плана и факта |
| `events` | что ты сделал в хабе: проекты Claude читают это в начале сессии |
| `meta/hub` | адрес хаба, чтобы подставлять его в блок для проектов |

Если на странице определена функция `window.HUB_SEED`, хаб работает без базы, на данных из неё. Так устроено демо.
